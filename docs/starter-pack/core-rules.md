# Choose what reaches the reviewer

Every Visualping change event includes a binary IMPORTANT flag and an AI Summary. The rule defines what matters. Delivery can include every captured edit or only IMPORTANT changes. Check the capture region first: text excluded from it cannot be assessed by the rule.

Replace bracketed scope before using these prompts. Linked-page instructions apply only to content captured from that page; add separate sources for document contents or details behind a listing.

## Trial record

Alert me when recruitment status, primary completion date, enrollment, arms, eligibility, primary outcomes or posted results change for this record. Report the exact changed field and published old and new values where available. Preserve estimated or actual qualifiers and keep unverified explanations separate.

Add site or country changes explicitly when needed. The bundled trial example was IMPORTANT=false under a narrower milestone rule; that result does not establish a detection failure.

## Pipeline

Alert me when an asset or indication is added or removed, changes phase, or changes published status. Identify the program and indication, report visible old and new values, and link to the source. Do not infer why a program changed.

## Brand or provider

Alert me when wording, an image, a claim, product prominence, price or stated availability changes in the selected region for [product/service]. Report the visible edit, however small. Keep a listing announcement separate from confirmation of current price or local stock.

Choose every-edit delivery when the brief requires every small edit. A relevance summary is still available for review.

## Congress

Alert me when [congress/year] adds, removes or changes a session, abstract title, presentation or published result for [topic/asset]. Report its identifier, date and visible change. Follow the linked abstract or presentation as a separate source when its contents matter.

## Guideline or access

Alert me when [guideline/HTA/payer source] publishes or changes relevant guidance, a coverage condition, recommendation or document for [asset/indication/geography]. Preserve draft/final status, population and jurisdiction. A new listing alone does not establish a positive recommendation.

## Regulatory approval

Alert me when this approval list adds an entry for [scope]. Report the product, ingredient, indication and approval date as published. If the label, safety detail or approval document matters, monitor its specific source separately.

## Review the setup

Save one relevant event, one small relevant edit and one routine edit as checks. Name who maintains the source list, inspects failures and reviews false alarms or missed known changes. Choose cadence from the decision deadline and available plan; the example cadence is not a guaranteed delivery time.
